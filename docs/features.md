# Реестр функций

Первоначально все функции имели статус `planned`. После приёмки 001–003 только F01–F05 имеют статус `done`; остальные не реализованы. Допустимые статусы: `in_progress`, `done`, `deferred`. `planned` означает запись в плане, а не утверждение предложенной механики. Приёмка зависимых функций уточняется после решений из [rules.md](rules.md). Ссылки на код и результаты проверок добавляются при реализации.

| F02 | RNG с seed и воспроизводимость | done | Одинаковый seed и сценарий дают одинаковый журнал и состояние; RNG миров независимы | 001, далее расширение |
