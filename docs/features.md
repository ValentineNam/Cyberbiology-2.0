# Реестр функций

Первоначально все функции имели статус `planned`. После приёмки 001–004, 006 и 007 F01–F10 имеют статус `done`; остальные не реализованы. Допустимые статусы: `in_progress`, `done`, `deferred`. `planned` означает запись в плане, а не утверждение предложенной механики. Приёмка зависимых функций уточняется после решений из [rules.md](rules.md). Ссылки на код и результаты проверок добавляются при реализации.
