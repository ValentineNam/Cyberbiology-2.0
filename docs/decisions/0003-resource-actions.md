# ADR 0003: закрытые ресурсы и биологический адаптер

Дата: 11 октября 2026 года. Статус: **принято** по контракту пользователя.

Точные параметры действий, питания и сенсоров приняты в [rules.md](../rules.md). Бюджет R = резерв + Σ(E+4*M) сохраняется: создание списывает эквивалент, энергия затрат возвращается резерву, питание переносит запасы, конверсии сохраняют эквивалент, удаление возвращает остаток.

Биологический слой владеет приватным техническим World и неизменяемыми ресурсными записями. Публичные операции этого слоя не дают обойти учёт бюджета. World остаётся независимым и совместимым с 001; VM — с 002. Прямое изменение приватных полей не является поддерживаемым интерфейсом.

Выбран минимальный явный параметр order у World.step: по умолчанию прежний порядок, при передаче — проверенный список различных существующих ID. Биологический шаг фиксирует только организмы и перемешивает их одним RNG мира. Это заменяет преимущество ранних ID без универсальной системы планировщиков.

Профили tree/bush/grass и останки — минимальные пищевые ресурсные записи. Жизненный цикл, наследование и мутации требуют отдельного решения 004.
