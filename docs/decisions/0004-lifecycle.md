# ADR 0004: фазы жизни, наследование и немедленная смерть

Дата: 11 октября 2026 года. Статус: **принято** по контракту пользователя.

Точные параметры и фазы — в [rules.md](../rules.md). Списки останков, растений и организмов фиксируются до тика; каждая живая фаза перемешивается непосредственно перед обработкой. Смерть заменяет ID новой записью останков, сохраняя запасы; полностью пустая клетка освобождается. Новорождённые и новые останки ждут следующего тика.

World получает минимальную общую операцию `run_tick(callback)` для одной синхронной транзакции счётчика, без отката состояния. Старый step сохраняет свою приёмку и использует тот же механизм. Биологический слой выполняет все фазы внутри одного run_tick, без отдельного step на фазу.

VM получает необязательный `is_active` callback после каждого действия; False возвращает `adapter_stopped`, который в биологическом слое обозначает смерть. Это не исключение и не обычный отказ действия. VM не знает организмов. Ошибки callback/адаптеров передаются вызывающему коду.

Все параметры конфигурируются; для проверок разрешены уменьшенные пределы возраста и вероятности мутации 0/100%. Наследуется полная независимая лента, направление и происхождение. Биологический успех и устойчивость популяции одним прогоном не доказываются.
