# ADR 0001: реактивное исполнение генома

Дата: 11 октября 2026 года. Статус: **принято** по решению пользователя.

## Контекст

Старая VM начинала вызов с нулевой ячейки. При переписывании нужно явно выбрать между реактивной программой и продолжением с сохранённого указателя. Ошибка общего массива генома в старом проекте не является частью механики.

## Решение

Каждый ход VM начинает исполнение с ячейки 0. Указатель между ходами не сохраняется. Исполнение ограничено бюджетом инструкций; завершающее действие заканчивает ход.

Наследуется весь геном, включая неисполняемые участки, без автоматического удаления. Мутации могут затронуть любую ячейку. Потомок получает независимый геном; его изменение не изменяет родителя и наоборот.

## Смысл и последствия

Программа каждый ход заново оценивает текущее состояние и окружение. Последовательность действий в разных ходах нельзя организовать только продолжением PC; если потребуется долговременная память, её нужно определить отдельным решением. Сброс PC сам по себе не запрещает такую память.

Неисполняемые участки — наследуемая часть программы. Они могут служить данными, оставаться нейтральными для текущей траектории или стать исполняемыми после изменения перехода, условий либо окружения. Их наличие сохраняет пространство возможных изменений, но не гарантирует эволюционную пользу. Анализ достижимости не даёт права сокращать геном.

Для независимости важен наблюдаемый результат, а не обязательный выбор конкретной структуры хранения: изменения одного носителя не отражаются у другого.

## Проверка при реализации

- После завершения на ненулевом адресе следующий ход снова начинает с 0.
- Цикл ограничивается бюджетом, а терминальное действие не допускает последующих инструкций в этом ходе.
- Недостижимый участок присутствует у потомка; его изменение не меняет родителя.
- Каждая ячейка доступна механизму мутации, независимо от исполнения; автоматической обрезки нет.

## Не решено этим ADR

Набор и кодировка инструкций, длина/диапазон генома, кольцевая адресация, память, величина бюджета, вероятности мутаций и завершение неудачной попытки. Новый набор из аудита остаётся предложением. См. [rules.md](../rules.md).
