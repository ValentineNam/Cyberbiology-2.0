# Задача 002: управляющая VM генома

Статус: **done**. Контракт принят пользователем.

Читать [правила](../rules.md), [архитектуру](../architecture.md), [реестр](../features.md), [результат 001](001-headless-world.md) и [ADR 0002](../decisions/0002-control-vm.md).

## Объём и границы

Независимая VM в `core/vm.py`, валидация генома, минимальные передаваемые сенсоры и исполнитель, переданный RNG. Python 3.13.0, стандартная библиотека и unittest. Без World/Entity, биологических механик, ресурсов, мутаций, API/UI, новых зависимостей и изменения legacy.

Интерфейс реализации: `execute(genome, sensors=..., perform=..., rng=...)`. Сенсоры имеют методы `front()` (целая категория 0–5 без bool) и `hungry()` (строго bool). Исполнитель `perform(action)` получает именованный код Action и возвращает bool успеха; отказ False не является исключением. Неверный тип результата адаптера — TypeError, неверная категория — ValueError; выполнение прекращается. Все исключения адаптеров передаются без подмены.

Геном принимается как последовательность, копируется в неизменяемую ленту после полной валидации: TypeError для неверного контейнера/типа ячейки, ValueError для длины или диапазона. RNG передаётся явно (обычно `world.rng`); случайный поворот делегируется исполнителю, который позднее обязан использовать RNG мира. Нормальное завершение возвращает неизменяемый ExecutionResult: instructions_executed, reason (terminal_action / budget_exhausted), last_pc. При исключении результата нет; побочные эффекты адаптеров не откатываются.

## Приёмка

- V01: повторный вызов стартует с 0; 16 нетерминальных инструкций исчерпывают бюджет; NOP/действия стоят одну инструкцию, операнды — ноль.
- V02: каждая терминальная инструкция заканчивает вызов при True и False; каждый поворот продолжает исполнение.
- V03: все шесть категорий впереди и оба исхода голода выбирают правильную ячейку; после перехода нет лишнего +1.
- V04: чтения операндов и переходы через конец кольцевые; нулевой операнд даёт 1; операнды исполняются, если на них попал PC.
- V05: JUMP_RANDOM воспроизводим при одинаковом состоянии RNG, использует включительные границы 1..limit; значения 12–31 — NOP и числовые данные.
- V06: геном не меняется; неверные длина/типы/значения отвергаются до сенсоров, действий и расходования RNG.
- V07: исключения каждого сенсора и исполнителя прекращают вызов и передаются вызывающему коду.
- V08: полный unittest, включая 001, проходит; минимальный пример известной программы работает без браузера; git diff --check проходит.

После проверки обновить только F04 и статус задачи; F05 остаётся planned. Не создавать коммит автоматически.
