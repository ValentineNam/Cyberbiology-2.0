# Задача 003: ресурсы и реальные действия VM

Вход: [rules](../rules.md), [architecture](../architecture.md), [features](../features.md), задачи [001](001-headless-world.md) и [002](002-genome-vm.md), [ADR 0003](../decisions/0003-resource-actions.md).

## Объём

Конфигурация принятых параметров, неизменяемые ресурсные записи организма/растения/останков, закрытый резерв, создание/чтение/техническое удаление/перемещение, направления, сенсоры, адаптер действий и биологический шаг. VM не привязывается к World. Публичное изменение запасов вне операций не предоставляется; параметры пользовательского создания валидируются до изменений/RNG.

Организм по умолчанию получает 256 E, 64 M, север; явные стартовые запасы допускаются в пределах ёмкости для контрольных сценариев, с оплатой из резерва. Растения/останки получают явно заданные неотрицательные запасы без пока не принятых биологических максимумов. Нехватка резерва при создании — явная ошибка без изменений; обычная неудача действия — False. Геном копируется в независимую неизменяемую ленту.

Нет метаболизма, смерти, роста, распада, рождения, мутаций, таймеров, API/UI, сохранения. Ресурсная сущность с нулевыми запасами остаётся на поле.

## Приёмка

- B01: все 8 направлений, повороты и края 17×11; успешный/заблокированный MOVE; недостаток энергии не списывает стоимость, TURN_RANDOM не расходует RNG при отказе.
- B02: все категории сенсора, дистанции геномов 0/2/3 и граница 5*E <= 1024.
- B03: питание организмом, тремя профилями растения и останками, пустота/граница, лимиты/нулевые запасы; цена до переноса и независимые минералы останков.
- B04: обе конверсии, нехватка запасов/ёмкости; фотосинтез с пустым/частичным резервом.
- B05: R и неотрицательность после создания, удаления, перемещения и каждого действия; ошибочные операции атомарны; входной геном не разделяется.
- B06: воспроизводимый порядок и итог, не более одного вызова VM после перемещения; снимок участников исключает новые ID и пропускает удалённые.
- B07: реальный IF_FRONT → поворот → MOVE; ограниченный пример с балансом.
- B08: все unittest 001–003 и git diff --check проходят.

Обновить F05 только после приёмки; F08 не завершать без жизненного цикла трёх растений. Коммит не создавать.

## Изменение контракта в 004

Описание отсутствия жизненного цикла и результаты 51 теста выше относятся к приёмке 003. В [004](004-lifecycle-evolution.md) нулевые запасы смертельны, стоимость действия может убить до его эффектов, растения имеют пределы профиля и фазы роста. Проверки цен, границ, валидации, RNG и бюджета сохранены. Текущие статусы — в реестре.
